# 🧳 Smart Tour

**Smart Tour** is an intelligent travel companion application designed to make travelling easier, safer, and more enjoyable. It helps users explore popular as well as **non-popular and unexplored tourist destinations across India**, while providing personalized travel recommendations and essential travel services in one platform.

## ✨ Features

- 🗺️ Explore popular and unexplored tourist places
- 🤖 Personalized tourist place recommendations
- 👥 Like-minded traveller recommendations
- 💰 Expense calculation and package comparison
- ⭐ Ratings and reviews
- 🌦️ Weather and disaster prediction
- 🚨 Shake Alert SOS emergency feature
- 💬 Chat and communication with agencies
- 🧑‍💼 Guide assignment and management
- 📸 Upload travel moments
- 📝 Complaint and feedback management
- 📢 Notifications and emergency alerts

## 👤 User Module

Users can:
- Register and login
- Search tourist places and agencies
- Get personalized recommendations
- Find like-minded travellers
- Add non-popular places
- Give ratings and feedback
- Upload photos and videos
- Chat with agencies
- Submit complaints
- Check weather and disaster predictions
- Send emergency SOS alerts using Shake Alert

## 🏢 Agency Module

Agencies can:
- Register and login
- Add and manage tourist places
- Verify and manage guides
- Assign guides
- Manage instructions
- Handle complaints and replies
- View emergency alerts

## 👨‍💼 Admin Module

Administrators can:
- Manage and verify agencies
- View tourist places
- View complaints and feedback
- Send notifications
- View emergency alerts
- Manage account settings

## 🧑‍✈️ Guide Module

Guides can:
- Register and login
- View assigned places
- Manage instructions
- View assignments
- Manage account settings

## 🤖 Recommendation System

Smart Tour uses **Machine Learning, NLP, user preferences, behaviour, and dataset analysis** to provide suitable tourist place recommendations. It also recommends travellers with similar interests.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, Bootstrap, JavaScript, Flutter
- **Backend:** Python Django / Flutter-Dart
- **Machine Learning:** ML, NLP
- **Database:** MySQL
- **Operating System:** Windows 8 or above

## 💻 Hardware Requirements

- Processor: i3 or above
- RAM: 4 GB or above
- Storage: 500 GB or above
- System: 32-bit or 64-bit
- Android-supported mobile phone

## 🎯 Objective

The main objective of Smart Tour is to provide an **all-in-one intelligent travel platform** that simplifies destination discovery, trip planning, budgeting, communication, personalized recommendations, and travel safety.

## 📌 Project Highlights

> **Explore. Plan. Connect. Travel Smart.**

Smart Tour aims to act not only as a travel guide but also as a **smart travel partner**, helping users discover new destinations and enjoy a safer and more personalized travel experience.
